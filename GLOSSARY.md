# Design-system glossary

- Foundation: framework-independent tokens, styles, fonts, assets and optional browser effects.
- Framework adapter: components that implement the foundation for one rendering framework.
- Product theme: a named set of semantic values and brand assets belonging to a product.
- Composition: reusable UI assembled from primitives, with product data and actions supplied by the consumer.
- Showcase: local examples that exercise the public packages without a product backend.
- Consumer: a product that installs a published package version.
