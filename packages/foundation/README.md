# @want-desyst/foundation

Shared design tokens, compiled styles, local fonts and brand resources. Import @want-desyst/foundation/styles.css and optionally @want-desyst/foundation/fonts.css. Read tokens through @want-desyst/foundation/tokens.json.

Browser effects are opt-in and return cleanup functions. Call burstConfetti with the clicked control; application events and downloads remain with the consumer.

See the repository README for usage, compatibility and release instructions.
